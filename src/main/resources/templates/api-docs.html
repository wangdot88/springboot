工单管理系统 API 文档

系统功能概述

本工单管理系统提供以下核心功能：

  • ✅ 用户创建工单，支持工单分类和优先级
  • ✅ 工单状态管理（待处理、处理中、已解决、已关闭）
  • ✅ 自动分配工单和手动分配工单
  • ✅ 工单转交功能
  • ✅ 文字和图片回复工单
  • ✅ 工单处理时间要求和关闭工单
  • ✅ 用户评价打分功能（最高5分）
  • ✅ 工单统计功能（数量和平均解决时间）

工单管理 API

  • POST /api/tickets/create 创建工单
  • GET /api/tickets/user/{userId} 获取用户的工单列表
  • GET /api/tickets/{ticketId} 获取工单详情
  • PUT /api/tickets/{ticketId}/status 更新工单状态
  • PUT /api/tickets/{ticketId}/assign 手动分配工单
  • PUT /api/tickets/{ticketId}/auto-assign 自动分配工单
  • PUT /api/tickets/{ticketId}/transfer 转交工单
  • POST /api/tickets/{ticketId}/reply 回复工单
  • GET /api/tickets/{ticketId}/replies 获取工单回复列表
  • PUT /api/tickets/{ticketId}/close 关闭工单
  • GET /api/tickets/categories 获取工单分类

评价管理 API

  • POST /api/reviews/create 创建工单评价
  • GET /api/reviews/ticket/{ticketId} 获取工单评价
  • GET /api/reviews/average-rating 获取平均评分
  • GET /api/reviews/statistics 获取评分统计

统计 API

  • GET /api/statistics/tickets 获取工单统计信息
  • GET /api/statistics/agent-workload 获取客服工作量统计
  • GET /api/statistics/tickets/date-range 获取时间段内的工单统计

使用说明

1. 首先使用测试用户登录系统

2. 客户用户可以创建工单并查看自己的工单

3. 客服用户可以处理分配的工单，回复工单，更新工单状态

4. 管理员可以管理所有工单，分配工单，查看统计信息

5. 工单解决后，客户可以对工单进行评价打分

6. 系统支持自动分配工单给工作量最少的客服

7. 支持工单转交功能，方便客服之间的协作
